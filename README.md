##  繁體中文

### 📌 專案簡介
**蘇北公車票價查詢工具 (Subo-Bus-Fare-Inquiry-Tool)** 是一個透過簡單易用的網頁，選取路線號、上下行方向和上下車站點，即可查詢蘇北地區部分分段式計費公車票價的實用工具。旨在方便您的日常出行，防止被黑車亂收費。

### ✨ 主要功能
* **路線選擇**：輕鬆篩選蘇北地區的公車路線。
* **方向與站點匹配**：支援選擇上下行方向及起終點站。
* **即時票價計算**：快速獲取分段式計費的精確票價。

## English

### 📌 Overview
**Subo-Bus-Fare-Inquiry-Tool** is a user-friendly web interface designed to calculate segmented bus fares in the Subo area. By allowing users to select the route number, direction, and boarding/alighting stops, it helps streamline daily commutes and prevents overcharging by black cars.

### ✨ Features
* **Route Selection**: Easily browse available bus lines across Subo area.
* **Direction & Stop Filter**: Choose bound direction and specific boarding/alighting stops.
* **Instant Fare Calculation**: Accurately computes tiered fare structures.

### 🤝 Data Contribution
Data is still incomplete! We warmly welcome contributions from the community. If you have access to the latest official tiered fare schedules from bus operators, please contribute by:
1. Submitting a **Pull Request** with updated data files.
2. Opening an **Issue** with screenshots or official links.

### ⚠️ Disclaimer
> **Notice**: Fare information generated by this tool is for reference only. Please refer to official announcements and actual charges by operating transit companies.
